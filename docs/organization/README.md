# Organizational knowledge documents

`mock/` contains **nine fictional test documents** for TOM Governance AI Demo, not Tom of Finland Foundation's authentic mission, bylaws or policy. All have `status: simulated`, `authoritative: false`, `approval_status: not_applicable`, and `classification: public_demo`.

Authenticity differs from applicability: mock sources can exercise a fictional scenario, but never support an authentic organizational permission finding. The real organization layer is intentionally empty until authoritative documents are supplied and verified by a human operator. Do not store confidential source files in this repository. Use protected backend ingestion.

`templates/` provides metadata examples for genuine organizational documents and proposed policies. Review `docs/application/document-processing.md` before designating authority. Source metadata, immutable versions, exact quotations and human approval evidence are mandatory for credible traceability.
